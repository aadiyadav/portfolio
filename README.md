# My Portfolio Website

Welcome to my portfolio website! This project showcases my personal and professional journey, highlighting my skills, projects, and more.

## Tech Stack

- **React.js**: A JavaScript library for building user interfaces.
- **Vite**: A build tool that provides a faster and leaner development experience for modern web projects.
- **TailwindCSS**: A utility-first CSS framework for rapid UI development.
- **Vanta.js**: A library built on Three.js for creating animated 3D backgrounds.

## Features

- **Responsive Design**: The website is fully responsive and works seamlessly on all devices.
- **3-D Interactive Background**: The landing page features a 3-D interactive background that rotates smoothly with cursor or device movement.
- **Typing Animation**: Engaging typing animation on the landing page to capture attention.
- **Hover Animations**: Underline animations on hover for various elements to enhance user interaction.
- **Resume Download**: Users can download my resume directly from the website.
- **Project Showcase**: Each project includes a GitHub link, a live deployed link, and the tech stack used.

## Pre-requisites

Before you begin, ensure you have met the following requirements:

- **Node.js**: Make sure you have Node.js installed on your machine. You can download it from [nodejs.org](https://nodejs.org/).
- **npm**: Node.js installation comes with npm. Ensure it's up to date by running `npm install -g npm`.

## How to Run the Project Locally

To run this project on your local machine, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/aadiyadav/portfolio.git
   cd portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   # or
   yarn install
   ```

4. **Start the Development Server**:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

5. **Open in Browser**:
   Open your browser and navigate to `http://localhost:5173` to view the website.
